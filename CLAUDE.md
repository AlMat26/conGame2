# CLAUDE.md

## Проект

**conGame** — консольный многопользовательский выживач на C++ (2–4 игрока,
реальное время). Старый проект автора (2023), который сейчас возрождается.

Задуманное: процедурно генерируемый ограниченный мир из чанков (задел на
бесконечный), вода с анимацией, берег, деревья, скалы; копание и установка
блоков; заброшенные шахты (подземные уровни), темнота и свет, обвалы
широких выработок и крепь (ставится автоматически за дерево), руда;
в планах — факелы.
Графика — классический ASCII: символ на чёрном фоне, 8 цветов.

## Модули

- `ConRender/` — класс `ConRender`, вывод в терминал через ncurses.
  Координаты `printxy(str, x, y)` отсчитываются от центра экрана, ось Y вверх,
  `setViewPosexy` смещает «камеру». Всё, что за краем экрана, отсекается.
  Цвета — `addColor(fg, bg, bold)` возвращает номер, который передаётся в `printxy`;
  `bold` в 8 цветах даёт яркий вариант (жёлтый вместо коричневого).
  `setInputTimeout(ms)` делает ввод неблокирующим (`getInput` вернёт `ERR`),
  при изменении размера окна `getInput` вернёт `KEY_RESIZE`.
  Только ASCII: отсечение считает байты, а не символы UTF-8.
- `Network/` — TCP через Boost.Asio, **неблокирующие** сокеты: сеть опрашивается
  каждый кадр и не останавливает игровой цикл. `NetworkServer` (`start`,
  `acceptConnection` → id или -1, `send`/`receive` по id, `isConnected`,
  `disconnect`, `getLocalAddress`) и `NetworkClient` (`connectTo` — блокирующий,
  `send`/`receive`, `isConnected`). `receive` возвращает `true`, только если пришло
  целое сообщение; потерю связи видно по `isConnected`. Сообщение — 4 байта длины
  (big-endian) + данные, лимит 1 МБ. Исключения не бросаются.
- `World/` — `World`: тайлы (`enum class Tile`), чанки 32×32, создаются лениво
  при первом обращении. Генерация — фрактальный value noise по seed: высота →
  глубокая вода / вода / песок / трава / скала, второй шум — лес. К краям мир
  уходит в океан (остров). Мир 8×8 чанков = 256×256. Ось Y вверх.
  Слои: `z = 0` — поверхность, `z = -1 … -mineDepth` — шахты; все методы
  принимают `(x, y, z)`. Шахты (входы, лестницы, комнаты, штольни) расставляет
  `generateMines` при создании мира; подземный тайл — `generateUndergroundTile`.
  `isOpaque` — сквозь что не идёт свет.
  Постройки: `RockFloor`, `Wall`, `Bridge`; `getGroundTile` — что было на клетке
  изначально (из генератора), туда клетка возвращается при разрушении постройки.
  Новые тайлы добавлять в конец `enum` (номер тайла уходит по сети)
  и обновлять `tileTypesCount`.
- `Game/` — `Game`: режимы `startSolo` / `startHost` / `startJoin`, игровой цикл
  (кадр 30 мс через `setInputTimeout`), игроки (до 4, массив `players`, id = слот,
  хост — 0), отрисовка с камерой на своём игроке, анимация воды, HUD.
  Внешний вид тайлов — `setLook` в конструкторе `Game`; несколько символов
  в строке — варианты, выбираются по хешу координат.
  Хост решает всё: клиент шлёт намерения, хост проверяет (соседняя клетка,
  проходимость, другие игроки, перезарядка: ход 30 мс, действие 150 мс)
  и рассылает результат. Действия (`tryDig` / `tryBuild`) — по направлению
  взгляда `facingX/facingY`; у клеток есть прочность (`getDurability`), удары
  копятся в `damages`. Изменения мира идут через `changeTile`, который
  запоминает их в `changedTiles` для новичков. Мир «живёт» (сброс повреждений,
  рост деревьев по `growthTimes`) только у хоста — `updateWorld`.
  Ключ клетки — `cellKey(x, y, z)` / `keyToCell`. Лестницы — в `tryMove`.
  Под землёй выкопанное игроками помнится в `dugCells`; если есть дерево —
  крепь по бокам (`placeSupports`). Устойчивость — `isStable`, проверка после
  копания — `checkCeiling`, обвал по таймеру `collapseTimes` — `collapse`.
  Инвентарь (`wood`, `ore`) — в `Player`, хранит хост, клиенту уходит `INV`;
  стены и мосты стоят дерево (`woodPerBuilding`), при разборе оно возвращается;
  подсказки игроку — `notify` (`NOTE`).
  Свет: `collectLights` (источники на уровне — сейчас игроки, потом факелы) →
  `computeLight` (карта освещённости экрана) → `getLight`; на поверхности
  всегда светло.
  Протокол — текст: клиент → хост `MOVE dx dy`, `DIG dx dy`, `BUILD dx dy`;
  хост → клиент `WELCOME id seed`, `TILE x y z type`, `DAMAGE x y z hits`,
  `POS id x y z`, `INV wood ore`, `NOTE текст`, `LEAVE id`, `FULL`.
- `main.cpp` — разбор аргументов, выбор режима, вывод итогового сообщения
  (ошибка подключения, «Disconnected from host» и т.п.).

## Стиль кода — ОБЯЗАТЕЛЬНО

**Весь код в этом репозитории пишется строго в стиле, описанном в
[`CODESTYLE.md`](CODESTYLE.md).** Прочитай его перед любой правкой кода.

Цель — чтобы новый код был неотличим от старого кода автора.
Не «улучшай» стиль на свой вкус: не меняй расстановку скобок и пробелов,
не переименовывай существующие сущности, не добавляй лишних комментариев,
не переписывай работающий код в «современный C++» без просьбы.
Отступать от старого стиля можно только для исправления ошибок —
их список в разделе «Что исправляем, а не копируем» в `CODESTYLE.md`
(утечки памяти, неинициализированные указатели и т.п.).

Не путать со стилем учебных лабораторных автора — для этого проекта
действует только `CODESTYLE.md`.

## Сборка

Зависимости и команды установки для разных систем (включая Termux) —
в [`README.md`](README.md). Кратко: CMake ≥ 3.10, компилятор C++, ncurses,
Boost ≥ 1.66 (только заголовки Asio).

При изменении зависимостей, команд сборки или запуска — обнови `README.md`.

```sh
cmake -S . -B build
cmake --build build
./build/congame
```

```sh
./build/congame                    # играть одному (случайный мир)
./build/congame play <seed>        # играть одному в мире с заданным seed
./build/congame host [port]        # хостить игру
./build/congame join <ip> [port]   # подключиться к хосту
```

Управление: стрелки / WASD — ходьба, `e` — копать, `r` — строить, `q` — выход.

Для игры по сети хост должен открыть порт в фаерволе (TCP, по умолчанию 9999).
Адрес — только IP, имена хостов (`localhost`, домены) не поддерживаются.

Папка `build/` в `.gitignore`, не коммитить её.
