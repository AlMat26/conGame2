# CLAUDE.md

## Проект

**conGame** — консольная сетевая игра на C++. Старый проект автора (2023),
который сейчас возрождается. На данный момент готов только каркас:

- `ConRender/` — класс `ConRender`, вывод в терминал через ncurses.
  Координаты `printxy(str, x, y)` отсчитываются от центра экрана, ось Y вверх,
  `setViewPosexy` смещает «камеру». Всё, что за краем экрана, отсекается.
  Цвета — `addColor(fg, bg)` возвращает номер, который передаётся в `printxy`.
  `setInputTimeout(ms)` делает ввод неблокирующим (`getInput` вернёт `ERR`),
  при изменении размера окна `getInput` вернёт `KEY_RESIZE`.
  Только ASCII: отсечение считает байты, а не символы UTF-8.
- `Network/` — TCP через Boost.Asio, два класса:
  `NetworkServer` (`acceptConnection`, `send`/`receive` по номеру клиента)
  и `NetworkClient` (`connectTo`, `send`/`receive`). Сообщение передаётся как
  4 байта длины (big-endian) + данные. Ошибки сети возвращаются как `false`,
  исключения не бросаются.
- `main.cpp` — тест соединения: хост и клиент обмениваются приветствиями.
  Режим задаётся аргументами (`host [port]`, `join <ip> [port]`),
  без аргументов — меню `s` / `c` (клиент идёт на `127.0.0.1`). Порт по умолчанию 9999.

Игровой логики, игрового цикла и протокола пока нет.

## Стиль кода — ОБЯЗАТЕЛЬНО

**Весь код в этом репозитории пишется строго в стиле, описанном в
[`CODESTYLE.md`](CODESTYLE.md).** Прочитай его перед любой правкой кода.

Цель — чтобы новый код был неотличим от старого кода автора.
Не «улучшай» стиль на свой вкус: не меняй расстановку скобок и пробелов,
не переименовывай существующие сущности, не добавляй лишних комментариев,
не переписывай работающий код в «современный C++» без просьбы.
Отступать от старого стиля можно только для исправления ошибок —
их список в разделе «Что исправляем, а не копируем» в `CODESTYLE.md`
(утечки памяти, неинициализированные указатели и т.п.).

Не путать со стилем учебных лабораторных автора — для этого проекта
действует только `CODESTYLE.md`.

## Сборка

Зависимости: CMake ≥ 3.10, компилятор C++, ncurses (`libncurses-dev`),
Boost ≥ 1.66 (`libboost-system-dev`, нужны только заголовки Asio).

```sh
cmake -S . -B build
cmake --build build
./build/congame
```

```sh
./build/congame host [port]        # захостить игру
./build/congame join <ip> [port]   # подключиться
./build/congame                    # меню: s — хост, c — клиент на 127.0.0.1
```

Для игры по сети хост должен открыть порт в фаерволе (TCP, по умолчанию 9999).
Адрес — только IP, имена хостов (`localhost`, домены) не поддерживаются.

Папка `build/` в `.gitignore`, не коммитить её.
