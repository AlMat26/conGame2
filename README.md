# conGame

Консольный многопользовательский выживач в ASCII-графике.
Процедурно генерируемый остров, вода, леса, скалы; в планах — копание,
стройка, шахты и игра с друзьями по сети (2–4 игрока).

## Зависимости

- компилятор C++11 (GCC или Clang)
- CMake ≥ 3.10
- ncurses
- Boost ≥ 1.66 — только заголовки (Asio), собранные библиотеки Boost не нужны

### Ubuntu / Debian

```sh
sudo apt install build-essential cmake libncurses-dev libboost-dev
```

### Fedora

```sh
sudo dnf install gcc-c++ cmake ncurses-devel boost-devel
```

### Arch

```sh
sudo pacman -S base-devel cmake ncurses boost
```

### Termux (Android)

```sh
pkg install clang cmake make ncurses boost-headers git
```

Если пакета `boost-headers` нет в вашем зеркале — поставьте `boost`.
Для клонирования по SSH дополнительно нужен `openssh`.

## Сборка

```sh
git clone git@github.com:AlMat26/conGame2.git
cd conGame2
cmake -S . -B build
cmake --build build
```

## Запуск

```sh
./build/congame              # играть в случайном мире
./build/congame play 42      # играть в мире с seed 42 (у всех одинаковый)
./build/congame --help
```

Управление: стрелки или WASD — ходьба, `q` — выход.

### Проверка сети

Сетевой игры пока нет, есть тест соединения — хост и клиент обмениваются
приветствиями:

```sh
./build/congame host [port]        # в первом терминале
./build/congame join <ip> [port]   # во втором
```

Порт по умолчанию — 9999. Для игры по локальной сети на хосте нужно
открыть этот порт (TCP) в фаерволе. Адрес — только IP, имена хостов
не поддерживаются.

## Если что-то пошло не так

- **CMake не находит Curses или Boost** — не установлены пакеты из раздела
  «Зависимости».
- **После падения терминал без курсора и не показывает ввод** — наберите
  вслепую `reset` и нажмите Enter.
- **Старая папка `build/`** с чужими путями в `CMakeCache.txt` — удалите её
  и соберите заново.

## Структура

| Папка        | Что внутри                                                |
|--------------|-----------------------------------------------------------|
| `ConRender/` | вывод в терминал через ncurses: камера, цвета, ввод       |
| `Network/`   | TCP-сервер и клиент на Boost.Asio                         |
| `World/`     | тайлы, чанки, процедурная генерация острова               |
| `Game/`      | игровой цикл, игрок, отрисовка мира                       |
| `main.cpp`   | разбор аргументов командной строки                        |
