# conGame

Консольный многопользовательский выживач в ASCII-графике.
Процедурно генерируемый остров, вода, леса, скалы; можно рубить деревья,
копать скалы, строить стены и мосты — одному или с друзьями по сети
(2–4 игрока). В планах — шахты, обвалы, крафт.

## Зависимости

- компилятор C++11 (GCC или Clang)
- CMake ≥ 3.10
- ncurses
- Boost ≥ 1.66 — только заголовки (Asio), собранные библиотеки Boost не нужны

### Ubuntu / Debian

```sh
sudo apt install build-essential cmake libncurses-dev libboost-dev
```

### Fedora

```sh
sudo dnf install gcc-c++ cmake ncurses-devel boost-devel
```

### Arch

```sh
sudo pacman -S base-devel cmake ncurses boost
```

### Termux (Android)

```sh
pkg install clang cmake make ncurses boost-headers git
```

Если пакета `boost-headers` нет в вашем зеркале — поставьте `boost`.
Для клонирования по SSH дополнительно нужен `openssh`.

## Сборка

```sh
git clone git@github.com:AlMat26/conGame2.git
cd conGame2
cmake -S . -B build
cmake --build build
```

## Запуск

```sh
./build/congame              # играть одному в случайном мире
./build/congame play 42      # играть одному в мире с seed 42
./build/congame --help
```

Управление:

| Клавиша         | Действие                                                    |
|-----------------|-------------------------------------------------------------|
| стрелки / WASD  | ходьба; игрок поворачивается, даже если упёрся в препятствие |
| `e`             | копать / рубить клетку перед собой (она подсвечена)         |
| `r`             | построить стену, а на воде — мост                           |
| `q`             | выход                                                       |

### Игра с друзьями

Один игрок хостит, остальные (до трёх) подключаются к нему:

```sh
./build/congame host [port]        # хост
./build/congame join <ip> [port]   # друг
```

Хост видит свой адрес в верхней строке (`host 192.168.1.5:9999`) — его и
нужно сообщить друзьям. Порт по умолчанию — 9999; на хосте он должен быть
открыт в фаерволе (TCP). Адрес — только IP, имена хостов не поддерживаются.
Если хост выходит, игра заканчивается у всех.

Каждый игрок — `@` своего цвета (жёлтый — хост, затем голубой, фиолетовый,
красный); свой цвет показан в верхней строке.

## Если что-то пошло не так

- **CMake не находит Curses или Boost** — не установлены пакеты из раздела
  «Зависимости».
- **После падения терминал без курсора и не показывает ввод** — наберите
  вслепую `reset` и нажмите Enter.
- **Старая папка `build/`** с чужими путями в `CMakeCache.txt` — удалите её
  и соберите заново.
